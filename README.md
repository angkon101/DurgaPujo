An immersive, visually breathtaking, and culturally authentic web platform celebrating **Durga Puja (Sharodotsav)** — inscribed in 2021 on the **UNESCO Representative List of the Intangible Cultural Heritage of Humanity**.

Built with modern **HTML5**, **Vanilla CSS3**, and **Vanilla ES6 JavaScript** with a self-contained **Web Audio API percussion and sacred instrument synthesizer**. Zero external runtime dependencies, ultra-fast load times, and ready for instant deployment on GitHub Pages or Vercel.

---

## 🌟 Highlights & Key Features

### 🪔 1. Interactive Virtual Darshan & Aarti
- **Goddess Durga Pratima Sanctum**: High-resolution sanctum sanctorum featuring Maa Durga in traditional royal *Daker Saaj*.
- **Interactive Aarti Thali**: Move your cursor or enable auto-orbit mode to perform sacred evening Aarti with glowing flames and incense smoke.
- **Synthesized Ritual Instruments**:
  - 🐚 **Shankha (Sacred Conch)**: Deep resonant acoustic frequency sliding simulation.
  - 🔔 **Ghanta (Temple Brass Bell)**: Authentic bell harmonic modal overtones.
  - 🌺 **Pushpanjali Flower Offering**: Real-time cascading lotus and marigold flower shower onto the Goddess's feet.
  - 📜 **Maha Pushpanjali Mantra**: Sanskrit shloka with Bengali script, English translation, and audio voice synthesis.

### ⏳ 2. Live Festival Countdown Clock
- Real-time countdown clock tracking days, hours, minutes, and seconds to **Maha Shashthi Bodhon** and the auspicious **Sandhi Puja**.
- Dynamic tithi indicator following the Ashwin Shukla Paksha panjika.

### 📅 3. Complete Festival Calendar & Ritual Timings
- Interactive day-by-day ritual guide with muhurats, customs, and traditional *Mahabhog* offerings:
  - **মহালয়া (Mahalaya)** — Tarpan, Chandipath at dawn, and Chokkhu Daan.
  - **মহা ষষ্ঠী (Maha Shashthi)** — Bodhon beneath the sacred Bilva tree and Adhibas.
  - **মহা সপ্তমী (Maha Saptami)** — Kola Bou (Nabapatrika) Snan & Prana Pratishtha.
  - **মহা অষ্টমী (Maha Ashtami & Sandhi Puja)** — Kumari Puja & lighting of 108 diyas.
  - **মহা নবমী (Maha Navami)** — Navami Homa fire oblation and ecstatic Dhunuchi dance.
  - **বিজয়া দশমী (Bijoya Dashami)** — Darpan Bishorjon, Sindoor Khela, and Shubho Bijoya.

### 🏮 4. Kolkata Pandal Parikrama & Hopping Explorer
- Filterable showcase of famous pandals (*Bonoedi/Heritage*, *Grand Palaces*, *Art & Contemporary*, *Eco-Friendly*):
  - **Sreebhumi Sporting Club** (Grand palatial architecture)
  - **Bagbazar Sarbojanin** (Centenary Daker Saaj tradition)
  - **College Square** (Illuminated water reflection)
  - **Sovabazar Rajbari** (Historic 1757 Bonedi Bari celebration)
  - **Santosh Mitra Square** (Contemporary illumination art)
  - **Chetla Agrani Club** (Eco-friendly terracotta art)
- Live-estimated crowd meters (Peaceful, Moderate, Peak), best visiting hours, and one-click Google Maps route navigation.

### 🥁 5. Interactive Dhak Rhythm Studio
- Synthesized Web Audio percussion pad triggered by clicks or keyboard keys `[1]` through `[6]`:
  - `1`: **Dha! (ধাঁ)** — Deep bass tom stroke.
  - `2`: **Ti-Ki (তি-কি)** — Crisp rim slap.
  - `3`: **Kure-Kure (কুড়ে)** — Double bounce stroke.
  - `4`: **Kashor (কাঁসর)** — High-frequency brass gong.
  - `5`: **Shankha (শঙ্খ)** — Resonant conch blow.
  - `6`: **Aarti Roll (আরতি রোল)** — Full celebratory crescendo roll.
- **Auto-Groove Loop**: One-click traditional *Dhunuchi Naach* rhythm player with animated frequency visualizer bars.

### 💌 6. Shubho Bijoya & Festive Greeting Card Generator
- Dynamic HTML5 2D Canvas card creator:
  - Customize Sender and Recipient names.
  - Choose between Bengali and English blessing presets.
  - Select royal color themes (*Royal Crimson*, *Midnight Star*, *Temple Amber*).
  - Instant **PNG Card Download** and **One-click WhatsApp Share**.

### 🤝 7. Community Diya Lighting & Bhog Token Seva
- **Global Diya Counter**: Devotees worldwide can light a virtual lamp; count persists across visits via `localStorage`.
- **Digital Bhog Pass Generator**: Instant digital token generator for community prasadam distribution.

## 💻 Tech Stack & Architecture

- **Markup**: Semantic HTML5 with complete OpenGraph metadata.
- **Styling**: Vanilla CSS3 using CSS Custom Properties, Glassmorphism, CSS Grid & Flexbox.
- **Logic**: Vanilla ES6 JavaScript (No frameworks or npm packages required).
- **Audio**: Web Audio API (real-time frequency synthesis; no broken external mp3 links).
- **Graphics**: HTML5 2D Canvas for Greeting Card generation and particle dust.
- **Typography**: Google Fonts (*Cinzel Decorative*, *Marcellus*, *Rozha One*, *Hind Siliguri*, *Plus Jakarta Sans*).

## 🚀 Getting Started Locally

### Quick Launch
1. Clone the repository:
   ```bash
   git clone https://github.com/angkon101/DurgaPujo.git
   cd DurgaPujo
   ```
2. Open `index.html` directly in any modern web browser, or serve it using any local HTTP server:
   ```bash
   # Using Python 3
   python -m http.server 8000

   # Or using Node npx
   npx serve .
   ```
3. Navigate to `http://localhost:8000` in your browser.

---

## 🌐 Deploying to GitHub Pages

1. Push the code to GitHub on the `main` branch:
   ```bash
   git add .
   git commit -m "Initialize Durga Puja 2026 Web Platform"
   git push -u origin main
   ```
2. In your GitHub repository:
   - Go to **Settings** > **Pages**.
   - Under **Build and deployment** > **Source**, select **Deploy from a branch**.
   - Select branch `main` and folder `/ (root)`.
   - Click **Save**.
3. Your site will be live at `https://angkon101.github.io/DurgaPujo/`.
